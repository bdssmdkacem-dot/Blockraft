# Source Reference Image — Blockraft

## Approved visual north star

The project owner has explicitly approved the uploaded Blockraft main-menu/world concept image (1536 × 1024 PNG) as the mandatory visual reference. It defines the target quality and direction for the main menu, voxel environments, biomes, lighting, landmarks, crafting/survival UI, and overall composition.

**Canonical repository path required for the original image:** `source/reference/blockraft_visual_north_star.png`

**Current status:** the image is available as a conversation upload, but this GitHub integration cannot upload its binary bytes directly. Therefore the original image is NOT yet present in the repository at the canonical path. ## Non-negotiable rules
- Preserve the uploaded original unchanged; do not redraw, regenerate, crop, or compress the canonical source.
- Use the image as an acceptance benchmark, not merely inspiration.
- Prepare asset previews and briefs before integrating production assets into the playable world.
- Compare actual Godot screenshots against the reference, including at Android screen size.
- Keep Blockraft's designs original: do not reuse Minecraft's logo, proprietary textures, characters, or UI.
- A successful build without visual comparison does not pass acceptance.

## Asset families to prepare before world integration
1. Block materials: grass, dirt, stone, sand, wood, leaves, ore, water.
2. Nature: oak variants, shrubs, flowers, grass tufts, biome vegetation.
3. Architecture: meadow cottage, village set, landmark castle, bridges, docks.
4. Terrain and vistas: mountains, rivers, waterfalls, oceans, floating islands.
5. Player and tools: original player model, pickaxe, axe, mining feedback.
6. Crafting and survival UI: inventory, crafting bench, hotbar, health/hunger, day/night indicators.
7. Main menu and feature panels: original Blockraft logo and readable mobile UI.

Each family must have a preview, dimensions/scale notes, materials, collision/LOD budget, and visual acceptance checklist before being marked production-ready.
