# Blockraft Visual North Star

The approved menu/concept image supplied by the project owner is the **mandatory visual acceptance reference** for the game's visual identity. It is not permission to copy Minecraft assets or branding; Blockraft must use original assets and a distinct identity while targeting comparable clarity, richness, and polish.

## Required repository asset

Store the original supplied image at:

`assets/reference/blockraft_visual_north_star.png`

Do not replace, crop, repaint, or overwrite the original. Any crops or annotations must be separate derived files. Before production world-building starts, verify that the original image is present in this path and visible in the GitHub repository.

## Acceptance use

Every production asset and gameplay scene should be compared against this reference for:
- Strong voxel silhouettes and readable block geometry.
- Rich but controlled palette, clear lighting, atmospheric depth, and legible focal points.
- Distinct biomes, memorable structures, rivers/waterfalls, forests, mountains, and floating-island silhouettes where appropriate.
- A cohesive premium presentation across menu, world, tools, crafting, survival, and building.
- Mobile readability and performance; visual complexity must be achieved with optimized geometry/materials.

The concept image is a style and quality target, not a literal blueprint. Use original Blockraft designs, textures, UI, characters, names, and compositions.
