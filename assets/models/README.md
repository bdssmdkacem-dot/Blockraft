# Initial Blockraft Models

- `voxel_oak_tree.obj` — voxel foliage tree for the Meadowlands.
- `meadow_cottage.obj` — small timber-and-plaster starter cottage.
- `crafting_bench.obj` — first crafting station landmark.
- `blockraft_palette.mtl` — shared original material palette.

Each OBJ references `blockraft_palette.mtl` in this directory. Import and inspect using Godot 4; open `scenes/asset_gallery.tscn` and run it directly for a first combined preview.

These are blockout-ready source meshes. They are not yet approved final art, and the reference-image, in-engine, and Android gates remain open. See `docs/FIRST_3D_ASSET_SET.md`.
