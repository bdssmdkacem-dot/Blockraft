# Blockraft — Visual Art Direction and Asset Gate

## Mandatory source image
The uploaded 1536×1024 Blockraft concept image is approved as the mandatory visual north star. Its canonical path is `source/reference/blockraft_visual_north_star.png`. The image itself is still awaiting binary upload; see `source/REFERENCE_IMAGE.md`. Do not claim it exists in GitHub until the PNG is actually committed.

## Visual pillars
1. Readable voxel construction with consistent grid and crisp silhouettes.
2. Distinct biomes, vegetation, palette and landmark architecture.
3. Premium lighting with contact shadows, haze, warm/cool contrast and restrained emissive lights.
4. Clear foreground, midground and background composition.
5. Coherent materials that remain distinguishable at Android screen sizes.
6. Original Blockraft IP; do not reuse Minecraft logos, proprietary textures, characters, or UI.

## Acceptance gates
- Reference PNG exists at the canonical path and opens from GitHub.
- Asset-family previews pass silhouette, material, scale and readability review.
- Assets pass Godot in-engine review with actual lighting, collision and camera.
- Android device review passes performance and touch-readability checks.
- A successful build alone does not pass visual acceptance.
